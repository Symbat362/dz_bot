# 📚 Homework Manager Bot

**Homework Manager** — это Telegram-бот для управления домашними заданиями, созданный для упрощения взаимодействия между учителем и учениками. Бот позволяет назначать индивидуальные задания, устанавливать дедлайны, принимать решения и вести учет успеваемости.

---

## ✨ Функционал

### 👨‍🏫 Для Учителя (Админа)
Учитель имеет доступ к **Админ-панели** с удобной клавиатурой:

1.  **Добавить ученика**
    *   Генерация уникального 4-значного кода доступа.
    *   Регистрация имени ученика в системе.
2.  **Новое задание**
    *   Отправка задания в любом формате (Текст, Фото, Документ/PDF).
    *   Выбор конкретного ученика из списка.
    *   Указание названия задания (например: *"Алгебра, стр. 10, №5"*).
    *   Установка дедлайна (дата и время).
3.  **Список учеников**
    *   Просмотр всех зарегистрированных студентов.
    *   **Управление учеником**:
        *   📂 **Проверить ДЗ**: Просмотр списка заданий ученика со статусами:
            *   🔴 — Не сдано
            *   🟢 — Сдано вовремя
            *   🟡 — Сдано с опозданием
        *   🗑 **Удалить ученика**: Полное удаление ученика и всех его данных из базы.
    *   **Управление заданием**:
        *   Просмотр деталей и файла решения.
        *   🗑 **Удалить задание**: Отмена выданного задания.

### 👨‍🎓 Для Ученика
Ученики используют упрощенный интерфейс с кнопками:

1.  **Регистрация**
    *   Вход в систему по уникальному коду, выданному учителем (вводится один раз).
    *   Автоматическая привязка Telegram аккаунта.
2.  **Мои задания**
    *   Постоянная кнопка меню для быстрого доступа.
    *   Список активных заданий с указанием дедлайнов.
3.  **Сдача решений**
    *   Выбор задания из списка.
    *   Отправка решения в виде фото или файла.
    *   Мгновенное уведомление учителя о сдаче.

## 🚀 Установка и Запуск

### Предварительные требования
*   Python 3.10 или выше
*   Установленный `uv` (рекомендуется) или `pip`

### Шаг 1. Клонирование репозитория
Скачайте проект на свой компьютер:
```bash
git clone https://github.com/your-username/homework-bot.git
cd homework-bot
```

### Шаг 2. Настройка окружения
Создайте файл `.env` в корневой папке проекта и заполните его своими данными:

```env
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_TELEGRAM_ID=123456789
```
*   `BOT_TOKEN`: Получите у [@BotFather](https://t.me/BotFather).
*   `ADMIN_TELEGRAM_ID`: Ваш цифровой ID в Telegram. Можно узнать у бота [@userinfobot](https://t.me/userinfobot).

### Шаг 3. Установка зависимостей

Если вы используете **uv**:
```bash
uv sync
```

Если вы используете стандартный **pip**:
```bash
pip install aiogram sqlalchemy aiosqlite pydantic-settings
```

### Шаг 4. Запуск бота
```bash
python main.py
```
*При первом запуске бот автоматически создаст базу данных `db.sqlite3`.*

### Шаг 5. Заполнение начальными данными (Опционально)
Для быстрого добавления списка учеников можно использовать скрипт `seed_students.py`.

1.  Откройте файл `seed_students.py`.
2.  Отредактируйте список `students`, добавив имена и коды доступа:
    ```python
    students = [
        ("Имя Ученика", "123456"),
        ...
    ]
    ```
3.  Запустите скрипт:
    ```bash
    python seed_students.py
    ```

## 📝 Сценарий использования

1.  **Запуск**: Админ запускает бота, открывается меню.
2.  **Добавление**: Админ нажимает "Добавить ученика", вводит имя "Арсен". Бот выдает код `4821`.
3.  **Вход ученика**: Арсен заходит в бота, нажимает `/start` и вводит код `4821`. Бот запоминает его.
4.  **Выдача ДЗ**: Админ нажимает "Новое задание", кидает PDF, выбирает Арсена, пишет "Контрольная", ставит дедлайн.
5.  **Сдача**: Арсен нажимает "Мои задания", выбирает "Контрольная", кидает фото решения.
6.  **Проверка**: Админ получает уведомление, заходит в "Список учеников" -> "Арсен" -> "Проверить ДЗ" и видит решение.
